BFS 기본 형태도 손에 익혀둔다.

```python
from collections import deque

q = deque([(0, 0)])
visited[0][0] = True

while q:
    x, y = q.popleft()

    for dx, dy in directions:
        nx = x + dx
        ny = y + dy

        if 0 <= nx < n and 0 <= ny < m:
            if not visited[nx][ny]:
                visited[nx][ny] = True
                q.append((nx, ny))
```

DFS 기본 형태도 확인한다.

```python
def dfs(node):
    visited[node] = True

    for nxt in graph[node]:
        if not visited[nxt]:
            dfs(nxt)
```
