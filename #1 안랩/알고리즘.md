좋아. **다익스트라부터 아래쪽 알고리즘들을 시험 직전에 훑을 수 있는 수준**으로 설명과 기본 코드까지 정리하면 이 정도가 적당해.

# 1. 다익스트라 Dijkstra

### 언제?

**한 지점 → 다른 지점들의 최단거리 + 음수 가중치 없음**

핵심은 **현재까지 거리가 가장 짧은 노드부터 처리**하는 것.

```python
import heapq

def dijkstra(graph, start):
    n = len(graph)
    dist = [float("inf")] * n
    dist[start] = 0

    heap = [(0, start)]

    while heap:
        cost, cur = heapq.heappop(heap)

        # 이미 더 짧은 경로를 찾았음
        if cost > dist[cur]:
            continue

        for nxt, weight in graph[cur]:
            new_cost = cost + weight

            if new_cost < dist[nxt]:
                dist[nxt] = new_cost
                heapq.heappush(heap, (new_cost, nxt))

    return dist
```

그래프 형태:

```python
graph = [
    [(1, 3), (2, 5)],  # 0 → 1 비용3, 0 → 2 비용5
    [(2, 1)],
    []
]
```

기억:

```text
최단거리 + 동일 비용 → BFS
최단거리 + 0/1      → 0-1 BFS
최단거리 + 양수/0   → Dijkstra
```

# 2. DP 동적 계획법

### 언제?

**큰 문제의 답을 이전에 계산한 작은 문제의 답으로 만들 수 있을 때.**

특히 `경우의 수`, `최댓값`, `최솟값` 문제에서 자주 등장.

예: 1칸 또는 2칸씩 이동할 때 n번째 계단까지 가는 방법 수.

```python
def solution(n):
    dp = [0] * (n + 1)

    dp[0] = 1
    dp[1] = 1

    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]

    return dp[n]
```

핵심은 **점화식을 찾는 것**.

```text
dp[i] = 이전에 구한 답들을 이용해 계산
```

DFS 완전탐색에서 **같은 상태를 계속 다시 계산하고 있다면 DP 가능성**도 생각하기.

# 3. 이분탐색 Binary Search

### 언제?

**정렬된 데이터에서 특정 값 탐색.**

매번 탐색 범위를 절반으로 줄인다.

```python
def binary_search(arr, target):
    left = 0
    right = len(arr) - 1

    while left <= right:
        mid = (left + right) // 2

        if arr[mid] == target:
            return mid

        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
```

복잡도:

```text
O(log N)
```

`N = 1,000,000`이어도 약 20번이면 탐색 가능.

# 4. Parametric Search

이분탐색의 코테형 응용.

### 언제?

**정답 자체가 숫자이고 "이 값이 가능한가?"를 판단할 수 있을 때.**

예:

> 작업을 완료하는 최소 시간을 구하라.

정답을 직접 계산하기 어렵다면:

```text
100초면 가능?
→ 가능

50초면 가능?
→ 불가능

75초면 가능?
...
```

처럼 정답 범위를 이분탐색한다.

```python
left = 최소값
right = 최대값

while left <= right:
    mid = (left + right) // 2

    if possible(mid):
        answer = mid
        right = mid - 1
    else:
        left = mid + 1
```

기억:

> **최소/최대값을 구하라 + X일 때 가능한지 쉽게 판단 가능 → Parametric Search 의심**

# 5. Heap 우선순위 큐

### 언제?

데이터가 계속 추가되면서 **현재 최솟값을 반복적으로 꺼내야 할 때.**

Python의 `heapq`는 최소 힙.

```python
import heapq

heap = []

heapq.heappush(heap, 5)
heapq.heappush(heap, 2)
heapq.heappush(heap, 8)

print(heapq.heappop(heap))  # 2
print(heapq.heappop(heap))  # 5
```

복잡도:

```text
push → O(log N)
pop  → O(log N)
최솟값 확인 heap[0] → O(1)
```

최대 힙이 필요하면 보통 음수 사용:

```python
heapq.heappush(heap, -value)

value = -heapq.heappop(heap)
```

다익스트라에서도 이 자료구조를 사용한다.

# 6. 누적합 Prefix Sum

### 언제?

**구간 합을 여러 번 물어볼 때.**

```text
arr = [1, 3, 5, 2, 4]
```

매번:

```python
sum(arr[left:right])
```

하면 한 번에 O(N).

미리 누적합을 만들면:

```python
prefix = [0]

for n in arr:
    prefix.append(prefix[-1] + n)
```

결과:

```text
arr     = [1, 3, 5, 2, 4]
prefix  = [0, 1, 4, 9, 11, 15]
```

구간 `[left, right)` 합은:

```python
prefix[right] - prefix[left]
```

로 **O(1)**에 계산 가능.

# 7. Union-Find

### 언제?

**두 노드가 같은 그룹에 속하는지 반복해서 확인하거나 그룹을 합칠 때.**

핵심 연산 두 개:

```text
find  → 얘가 어느 그룹인가?
union → 두 그룹을 합쳐라
```

```python
parent = list(range(n))

def find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])
    return parent[x]

def union(a, b):
    a = find(a)
    b = find(b)

    if a != b:
        parent[b] = a
```

같은 집합인지:

```python
if find(a) == find(b):
    print("연결됨")
```

대표 신호:

```text
두 노드가 연결되어 있는가?
그룹을 계속 합친다
사이클이 생기는가?
```

# 8. 최소 신장 트리 MST / Kruskal

### 언제?

모든 노드를 연결해야 하는데 **전체 연결 비용을 최소화**해야 할 때.

예:

```text
컴퓨터 100대를 모두 연결하되
케이블 설치 비용을 최소화
```

Kruskal은:

```text
1. 간선을 비용순 정렬
2. 가장 싼 간선부터 선택
3. 단, 사이클이 생기면 선택하지 않음
```

그래서 **Union-Find와 세트**로 많이 나온다.

```python
edges.sort()

total = 0

for cost, a, b in edges:
    if find(a) == find(b):
        continue

    union(a, b)
    total += cost
```

# 9. 플로이드-워셜

### 언제?

**모든 노드 → 모든 노드의 최단거리**

```python
for k in range(n):
    for i in range(n):
        for j in range(n):
            dist[i][j] = min(
                dist[i][j],
                dist[i][k] + dist[k][j]
            )
```

의미:

```text
i → j 직접 가기

vs

i → k → j
```

둘 중 짧은 것 선택.

복잡도:

```text
O(N³)
```

그래서 N이 작은 경우 사용.

# 10. 벨만-포드

### 언제?

**한 출발점 최단거리 + 음수 간선 존재 가능**

모든 간선을 `V-1`번 반복해서 확인한다.

```python
dist = [float("inf")] * n
dist[start] = 0

for _ in range(n - 1):
    for cur, nxt, cost in edges:

        if dist[cur] == float("inf"):
            continue

        if dist[nxt] > dist[cur] + cost:
            dist[nxt] = dist[cur] + cost
```

한 번 더 돌렸는데도 거리가 줄어든다면 **음수 사이클**이 존재할 수 있다.

복잡도:

```text
O(VE)
```

## 최종 암기표

| 문제 신호          | 떠올릴 것                 |
| -------------- | --------------------- |
| 동일 비용 최단거리     | **BFS**               |
| 0/1 가중치 최단거리   | **0-1 BFS**           |
| 양수/0 가중치 최단거리  | **Dijkstra**          |
| 음수 가중치 최단거리    | **Bellman-Ford**      |
| 모든 노드 간 최단거리   | **Floyd-Warshall**    |
| 같은 계산이 반복됨     | **DP**                |
| 정렬된 곳에서 찾기     | **Binary Search**     |
| 정답 X가 가능한지 판단  | **Parametric Search** |
| 최솟값을 계속 꺼냄     | **Heap**              |
| 구간 합을 반복 계산    | **Prefix Sum**        |
| 그룹 합치기/연결 판별   | **Union-Find**        |
| 모두 연결 + 총비용 최소 | **MST/Kruskal**       |

시험 대비 우선순위를 굳이 나누면 **다익스트라, DP, 이분탐색, Heap까지는 기본 구현을 알아두고**, 나머지는 문제를 봤을 때 "이 알고리즘을 쓰는 문제구나" 정도로 알아볼 수 있게 해두는 게 효율적이야.
